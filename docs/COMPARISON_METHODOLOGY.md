# Comparison methodology

These pages are **selection guides**, not measured rankings. They distinguish tool roles and provide questions to evaluate before adoption. A project is listed only if its public GitHub source is in `data/public_examples.json`.

## Evidence levels
1. **Source existence checked:** public repository was located. Does not verify claims, security or licensing.
2. **Documentation reviewed:** future manual evidence with review date and citation.
3. **Reproduced benchmark:** future reproducible tests with environment, dataset, commands, and confidence bounds.

Only level 1 is currently supported. Do not infer that inclusion implies levels 2 or 3. Do not assign numerical quality scores without verified comparable evidence.

## Maintenance
Update comparison claims and dates only after checking current sources. Add explicit criteria, reproducible evidence and limitations before claiming a winner.
