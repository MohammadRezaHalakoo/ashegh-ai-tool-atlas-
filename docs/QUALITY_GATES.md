# Public catalogue quality gates

The public atlas uses 24 independently selected repository examples. No private research registry is exported.

## Enforced checks
- Unique public repository IDs and public GitHub source links
- Static profile generation for every catalogue entry
- Source URL and sitemap URL for each profile
- Four criteria-based comparison guides
- JSON validity and Pages artifact checks
- GitHub metadata is fetched read-only; no indexed project code is executed

## Limitations
Metadata snapshots are observations, not benchmarks, security audits, endorsements, or license clearance. Missing metadata remains marked unavailable. A failed metadata fetch must not make the core public catalogue inaccessible.

## Reproducible evaluation protocol
Before publishing performance rankings, record workload, dataset rights, hardware, software versions, source commits, repeated trials, latency percentiles, memory usage, accuracy metrics and uncertainty. No measured rankings are currently claimed.
